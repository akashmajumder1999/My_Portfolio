namp cheat sheet(documentations)

below are some basic namp commands for network scanning and reconnaissance:

  • 2. OS detection

basic scan

use the following command to scan specific ip addres or domain.

            nmap: 192.168.1.1

OS detection

use the -0 flag to the detect the oparating system running on the terget maching.

            sudo nmap -0 terget-ip
